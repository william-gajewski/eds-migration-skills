# Resourcing and availability data template

Keep this information in an approved, access-controlled location the planning agent can read, or
provide the equivalent information in the request. This is a blank template: do not add actual
names, project details or OOO information to this skill repository.

Use ISO dates (`YYYY-MM-DD`) and specify each person's time zone, working hours and working days.
Keep only the minimum availability information needed for scheduling. Do not include OOO reasons
or other personal details.
