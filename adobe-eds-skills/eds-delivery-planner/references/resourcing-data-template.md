# Resourcing and availability data template

Copy this structure into an approved, access-controlled location that the planning agent can
read, or provide the equivalent information in the planning request. This is a blank template:
do not add actual names, project details or OOO information to this skill repository.

Use ISO dates (`YYYY-MM-DD`) and specify a time zone for working hours and meetings. Keep only the
minimum availability information needed for scheduling. Do not include OOO reasons or other
personal details.
